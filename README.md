# 🎨 AI Colorize – DeOldify Web App (Full Edition)

A powerful, production‑ready web application to colorize black‑and‑white images using **DeOldify**. Features a modern UI with dark mode, batch processing, progress tracking, and a before/after comparison slider.

---

## ✨ Features

- **Multi‑file upload** – process multiple images at once.
- **Live progress** – see per‑file and overall progress.
- **Interactive slider** – compare original and colorized versions.
- **Batch download** – download all colorized images as a ZIP.
- **Dark mode** – easy on the eyes.
- **Adjustable color intensity** – control the render factor.
- **Auto‑start** – process files immediately after upload.
- **Job queue** – handles multiple requests gracefully.
- **Automatic cleanup** – removes old jobs and temp files.
- **GPU/CPU auto‑detection** – runs on CUDA if available.
- **RESTful API** – can be used programmatically.
